# For Piyu — Ek Sawaal 💍

A proposal website for **Piyu** (Payal). Built as the next chapter after the
Diwali safe-space sites — same dark-violet glass aesthetic, but this time with
**shayari, games, and THE question**.

**Live:** https://prensenia.github.io/Payal-proposal/

## What's inside
- 🔒 **Lock screen** — only Piyu can open it (same hint as the Diwali site)
- ✍️ **Shayari chapters** — 6 original rhyming Hinglish shayaris (carousel, swipe + auto-play)
- 🎮 **Three games** — each win gives a 💜 key:
  1. **Dil Pakdo** — catch falling hearts, dodge the 💔, 30 seconds
  2. **Yaadon Ka Jodi** — memory match where every pair hides an inside joke
  3. **Piyu-o-meter** — a playful quiz where every answer is the right one
- 💍 **The question** — unlocked by all 3 keys: *"Will you be mine?"* with a runaway **Nahi** button and a confetti celebration on **Haan**
- 🌸 **Polaroid memories** + the Dil-wali reel
- 🧨 **Sky shot easter egg** — do not click
- 🎵 Soft piano-style music toggle (WebAudio, no files)
